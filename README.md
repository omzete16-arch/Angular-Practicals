### Practical-01 — Hello World in Angular

**Objective:** To build a simple 'Hello World' application using the Angular framework.

**Concepts Used:** @Component decorator, selector 'app-root', component template

### Practical-02 — Simple Timetable using Data Binding

**Objective:** To display a simple daily timetable (time + task rows) using Angular components and data binding.

**Concepts Used:** Component class data, array of objects, *ngFor, interpolation

### Practical-03 — String Interpolation

**Objective:** To demonstrate string interpolation by displaying dynamic values stored in a component class — title, username, today's date, a greeting from a method, and a simple expression.

**Concepts Used:** String interpolation {{ }}, component properties, method binding, expressions

### Practical-04 — Student Name List using Array

**Objective:** To display a list of 10 student names using an array in Angular.

**Concepts Used:** Arrays, *ngFor, index, template rendering

### Practical-05 — Weekly Timetable Grid

**Objective:** To build a weekly timetable grid — days as rows, periods as columns, subjects filled in a 2D array.

**Concepts Used:** 2D arrays, nested *ngFor loops, HTML tables

### Practical-06 — Student Portfolios

**Objective:** To display student portfolios as cards (name, course, project).

**Concepts Used:** Array of objects, *ngFor, card layout, component CSS

### Practical-07 — Two-Way Data Binding

**Objective:** To demonstrate two-way data binding with a student information form.

**Concepts Used:** FormsModule, [(ngModel)], input fields, live value display

### Practical-08 — Simple Routing

**Objective:** To create an Angular application demonstrating simple routing with Home / About / Contact navigation.

**Concepts Used:** Routes, RouterLink, RouterOutlet, navigation

### Practical-09 — Route Parameters

**Objective:** To define route parameters and retrieve data in components — /student/101, /student/102, /student/103 links that show the student ID on the details page.

**Concepts Used:** Parameterized routes, ActivatedRoute, paramMap

### Practical-10 — Hello World in React

**Objective:** To build a Hello World React app.

**Concepts Used:** Function components, JSX

### Practical-11 — Counter Application

**Objective:** To create a counter app — increment, decrement and reset a number using React state.

**Concepts Used:** useState, event handling, state management

### Practical-12 — To-Do List

**Objective:** To create a to-do list — add, edit, mark complete, and delete tasks using React state.

**Concepts Used:** useState, arrays, map(), filter(), CRUD operations

### Practical-13 — Calculator

**Objective:** To create a calculator for basic arithmetic operations using React.

**Concepts Used:** useState, controlled inputs, event handling

### Practical-14 — Digital Clock

## 🚀 How to Run Angular Practicals

1. Install Node.js and check: `node --version` and `npm --version`
2. Install Angular CLI: `npm install -g @angular/cli`
3. Create a project: `ng new angular-practical`
4. Copy the practical's `app.ts` / `app.html` files into `src/app/`
5. Start the server: `ng serve` and open http://localhost:4200

## ⚛️ How to Run React Practicals

1. Create a project: `npm create vite@latest react-practical -- --template react`
2. Enter the project: `cd react-practical`
3. Install dependencies: `npm install`
4. Replace `src/App.jsx` with the practical's `App.jsx`
5. Start the server: `npm run dev` and open the URL shown (usually http://localhost:5173)
